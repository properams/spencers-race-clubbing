# Handovers

Eén handover **per sessie**, ongeacht omvang. Dit is de kernregel uit `../../CLAUDE.md`.

## Hoe
1. Kopieer `SESSION_HANDOVER_TEMPLATE.md` naar `JJJJ-MM-DD_korte-titel.md`.
2. Vul alle secties in; laat geen `< >`-placeholders staan.
3. Werk waar nodig `../DECISIONS.md`, `../CHANGELOG.md`, `../PATTERNS.md`,
   `../LESSONS.md` en `../BACKLOG.md` bij — de handover verwijst ernaar, herhaalt ze niet.
4. Commit de handover samen met (of direct na) het werk van de sessie.

## Waarom
Zonder handover is een sessie niet af: de volgende sessie (of Jur) mist context,
autonome keuzes en openstaande vragen. Deze discipline ontbrak eerder omdat het
template in een aparte repo leefde (zie `../LESSONS.md`).
